# 📚 2027 세무직 누적 학습 노트

2027년도 국가직 9급 세무직(세법·회계학·국어·영어) 대비 **누적 학습 카드** 정적 웹 앱입니다.
GitHub Pages로 바로 열리는 단일 페이지 앱이고, 학습 내용은 `data/` 폴더의 JS 파일에만 담겨 있습니다.

- 사이트: https://yoonmyn0328-arch.github.io/tax-study-hub/
- 시험일(D-day) 기준: 2027-03-27

## 구조

```
index.html                 화면 뼈대
assets/styles.css          디자인 (다크/라이트, 모바일 우선)
assets/app.js              검색·필터·복습 진행률·OX 퀴즈
data/items-tax.js          세법 (법인세법·국세징수법)
data/items-accounting.js   회계학
data/items-korean.js       국어
data/items-english.js      영어
```

`data/*.js`는 각각 `window.STUDY_ITEMS.push(...)`로 카드를 배열에 넣습니다.
빌드 도구나 서버가 필요 없고, `index.html`을 그대로 열어도 동작합니다(스크립트 로드 방식이라 CORS 없음).

## 카드 추가하는 법

해당 과목 파일의 `push(...)` 마지막 항목 뒤에 이어 붙이면 됩니다.

```js
{
  id: "tax-54",                       // 파일 안에서 겹치지 않게
  subject: "세법",                     // 세법 | 회계학 | 국어 | 영어
  topic: "법인세법 · 감가상각",          // 카드 상단 회색 줄
  title: "한 줄 제목 (결론이 드러나게)",
  date: "2026-11-19",                 // 학습한 날
  tags: ["상각범위액", "월할"],          // 검색에 잡힘
  analogy: `💡 생활 비유로 뼈대 잡기`,
  principle: `🔍 왜 그런지(원리)`,
  trap: `🎣 출제자 낚시 포인트`,
  example: `📝 기출·숫자 예시`,
  ox: { q: "OX 문제", a: true, why: "해설" }   // quiz에 쓰임
}
```

- `analogy` 등 본문은 **줄바꿈**으로 문단을 나누고, `- `로 시작하는 줄은 목록이 됩니다.
- 강조는 `**굵게**`만 지원합니다.
- `ox`가 없는 카드는 퀴즈에 출제되지 않습니다.

## 화면 기능

- **D-Day**: 2027-03-27까지 남은 날짜·시간 실시간 표시
- **과목 탭**: 전체 / 세법 / 회계학 / 국어 / 영어 (과목별 카드 수 표시)
- **검색·필터**: 키워드, 학습일, `복습 대기`, `★ 별표만` — 선택 상태는 브라우저에 저장
- **카드**: 비유·뼈대 → 원리 → 낚시 포인트 → 기출·숫자 예시(접기), 별표·복습 완료 토글
- **OX 복습**: 현재 필터에 걸린 카드에서 10문항 출제, 즉시 정답·해설
- **다크/라이트 모드** 전환

## 갱신

하루 공부가 끝나면 `data/` 파일에 카드를 추가하고 `main` 브랜치에 push하면 1분 안에 사이트에 반영됩니다.
